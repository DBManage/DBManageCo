DB Manage — Phone + Computer Sync

1. Create a Supabase project.
2. In Supabase, open SQL Editor and run supabase-setup.sql.
3. Open Project Settings / Connect (or API keys) and copy:
   - Project URL
   - Publishable key (or legacy anon key)
   Never put the service_role/secret key in this HTML.
4. Open index.html and replace:
   PASTE_YOUR_SUPABASE_PROJECT_URL_HERE
   PASTE_YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY_HERE
5. Upload the updated index.html to the same place you currently host the program.
6. Open it on the computer, create/sign into your DB Manage account.
7. Open the same URL on the phone and sign in with the same account.

The first device can migrate the existing projects stored in its old browser localStorage
if the new Supabase database is empty. After that, projects are stored in Supabase and
Realtime changes are pushed to the other device automatically.

Security:
- The browser uses only the public/publishable (or anon) key.
- Row Level Security limits project rows to the signed-in user.
- Do NOT put a service_role/secret key in index.html.
